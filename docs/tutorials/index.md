# Tutorials

Hands-on lessons that take you from your first session to using Vix's
deeper features. Each one is a set of steps you do in Vix, mostly against
the demo workspace that ships in the repository:

```sh
cd tui/examples/demo-workspace
vix .
```

Do the first three in order; after that, pick what you need.

## The basics

1. [Your First Session](01-your-first-session/index.md): the file explorer,
   tabs, the command palette, the menu bar, the status bar and the docks.
2. [Editing Power Techniques](02-editing-power-techniques/index.md): macros,
   snippets, text transforms and structural moves.
3. [Find & Replace and Multi-Cursor](03-find-replace-and-multi-cursor/index.md):
   searching one file or the whole workspace, and editing in many places at
   once.
