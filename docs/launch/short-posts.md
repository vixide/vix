Vix is a terminal text editor with a menu bar, the shortcuts you know, and the
IDE pieces you miss: language servers, a debugger, Git and a database workbench.
2.0 adds remote editing over SSH and containers (experimental), real-time
co-editing (opt-in build), a code-aware chat menu and a Large File Viewer.
`brew install vixide/homebrew-tap/vix-tui`, then `vix`. [LINK]
