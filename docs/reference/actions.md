# Action Reference

Generated by `cargo run --example list_commands -- --write` (T305, `tasks.md`) — do not edit by hand. Every action id [`App::run_action`](https://github.com/vixide/vix) can dispatch, with the title it resolves to and where that title comes from: a **Menu** leaf, this workspace's `vix-action-catalog` (**Catalog**, for ids with no menu leaf of their own), or a `palette::COMMANDS` entry (**Palette**, the few ids titled only there).

A handful of ids are dynamically suffixed (`view.theme:Dark`, `script:my_script`, …) rather than literal — their bare prefixes (`view.theme:`, `view.locale:`, `view.keymap:`, `script:`, `view.time_zone:`) are exempt from this list; see `vix_action_catalog::dispatch_scan::DYNAMIC_PREFIXES`.
