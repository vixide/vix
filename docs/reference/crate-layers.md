# Crate Layers

Generated by `cargo run --example list_commands -- --write` (T833) from
`cargo metadata`; do not edit by hand. `scripts/check` fails when it is stale.

A crate's *layer* is the longest chain of workspace dependencies below it:
layer 0 crates depend on no other workspace crate, and every crate depends
only on crates in lower layers. Dependencies are the direct normal and build
dependencies on other workspace members (dev-dependencies do not count);
*dependents* is how many members depend on the crate directly. The rules this
graph must keep are in the [architecture overview](../architecture/index.md#layering-rules),
enforced by `tui/tests/crate_layering.rs`.
