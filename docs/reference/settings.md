# Settings Reference

Generated by `cargo run --example list_commands -- --write` (T305, `tasks.md`) — do not edit by hand. Every [`Settings`](../../crates/vix-settings/spec/index.md) field: its persisted key (the flat TOML key in `config.toml`), its Rust type, its default value, and its doc comment.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `line_numbers` | `bool` | `true` | Show the line-number gutter. |
| `relative_line_numbers` | `bool` | `false` | Show line numbers relative to the cursor line (hybrid: cursor line absolute). |
| `show_whitespace` | `bool` | `false` | Render visible glyphs for whitespace (space, tab, line ending). |
| `soft_wrap` | `bool` | `false` | Wrap long lines across screen rows instead of scrolling horizontally. |
| `show_explorer` | `bool` | `true` | Show the file explorer on startup. |
| `explorer_delete` | `String` | `"trash"` | How the file explorer's Delete acts: `"trash"` (default — move to the OS trash/Recycle Bin, undoable from there) or `"hard"` (remove outright, `fs::remove_file`/`remove_dir_all`, no undo). Any other value falls back to `"trash"`, the safer default, rather than silently hard-deleting on a typo. |
| `show_messages` | `bool` | `true` | Show the message drawer on startup. |
| `show_status_bar` | `bool` | `true` | Show the bottom status bar. |
| `show_breadcrumbs` | `bool` | `false` | Show the breadcrumb bar (file ▸ enclosing symbol) above the editor. |
| `show_outline_dock` | `bool` | `false` | Show the code-outline sidebar (symbol list that follows the cursor). |
| `show_scrollbar` | `bool` | `true` | Show the editor's right-side scroll bar. |
| `show_bottom_dock` | `bool` | `true` | Show the bottom dock (log/output/data panel). |
| `bottom_dock_height` | `u16` | `9` | Height (rows) of the bottom dock; drag its top edge to resize. |
| `scrollback` | `usize` | `1000` | Maximum lines retained in the bottom dock (scrollback); oldest dropped past this. |

| `trim_trailing_whitespace` | `bool` | `true` | On save, strip trailing spaces/tabs from every line. |
| `ensure_final_newline` | `bool` | `true` | On save, append a final newline if the file does not end with one. |
| `format_on_save` | `bool` | `false` | On save, run the language server's formatter (when the file has one). |
| `auto_save` | `bool` | `false` | Periodically save the active dirty file-backed buffer (every few seconds). |
| `sticky_scroll` | `bool` | `true` | Pin the enclosing scope's header line at the top of the editor while scrolling (sticky scroll). |
| `rainbow_brackets` | `bool` | `false` | Color matching brackets by nesting depth (rainbow brackets). |
| `persistent_undo` | `bool` | `true` | Persist each file's undo tree across sessions (restored on reopen when the file content still matches). |
| `show_minimap` | `bool` | `false` | Show a code-overview minimap column at the right of the editor. |
| `show_menu_tooltips` | `bool` | `true` | Show hover tooltips (help text) on the menu bar's menus and items. |
| `highlight_word` | `bool` | `false` | Passively highlight every occurrence of the word under the cursor. |
| `indent_style` | `String` | `"spaces"` | Indentation inserted by Tab: `"spaces"` (default) or `"tabs"`. |
| `tab_width` | `usize` | `4` | Number of spaces per indent when `indent_style` is `"spaces"`. |
| `wrap_column` | `usize` | `80` | Column that Edit → Wrap hard-wraps (fills) text at. |
| `theme` | `String` | `"dark"` | Color theme: `"dark"` (default) or `"light"`. |
| `locale` | `String` | `"en"` | UI language as a locale code (e.g. `"en"`, `"es"`, `"fr"`, `"de"`, `"cy"`). Used as the default; a `--locale` CLI flag overrides it for one run. |
| `keymap` | `String` | `"apple"` | Keyboard navigation style id: `"apple"` (default), `"vscode"`, `"emacs"`, or `"vi"`. |
| `explorer_width` | `u16` | `30` | Width (columns) of the left dock (file explorer); drag its right edge to resize. |
| `messages_width` | `u16` | `32` | Width (columns) of the right dock (message drawer); drag its left edge to resize. |
| `outline_width` | `u16` | `28` | Width (columns) of the code-outline sidebar. |
| `debug_width` | `u16` | `36` | Width (columns) of the debugger panel (call stack / variables / watch). |
| `recent_files` | `Vec<String>` | `[]` | Recently opened files, most-recent first (absolute paths). Capped to recent_files_max; surfaced by **File → Open Recent…**. |
| `recent_files_max` | `usize` | `15` | How many entries to keep in recent_files. |
| `command_recents` | `Vec<String>` | `[]` | Action ids of commands recently run from the command palette, most-recent first; surfaced at the top of the `>` command list. |
| `spellcheck` | `bool` | `false` | Underline misspelled words in comments and strings. |
| `dictionary_path` | `String` | `""` | Extra directory to search for Hunspell dictionaries, on top of the autodetected standard locations. Empty = autodetect only. Both the `<dir>/<name>.{aff,dic}` and `<dir>/<name>/index.{aff,dic}` layouts work. |
| `lsp_enabled` | `bool` | `true` | Master switch for Language Server Protocol features (diagnostics, hover, go-to-definition, completion). When off, no servers are launched. |
| `lsp_servers` | `Vec<LspServer>` | `[]` | Configured language servers, matched to files by extension. Each entry is a language id (sent to the server), the file extensions it handles, and the command (program + args) to launch. Empty by default — Vix ships no built-in server, so add the ones you have installed, e.g. `{ language_id = "rust", extensions = ["rs"], command = ["rust-analyzer"] }`. |
| `show_welcome_dialog` | `bool` | `true` | Show the welcome dialog on launch. Vix sets it to `false` and saves the settings as soon as the dialog has been shown once, so it appears on the first run only; set it back to `true` to see it again. |
| `contacts_dir` | `String` | `""` | Directory of vCard (`.vcf`) files for the contact browser (Tools → Contacts…). Empty = use the workspace root. |
| `org_capture_templates` | `Vec<vix_org_capture::CaptureTemplate>` | `[{"clock_in":false,"description":"Anything","empty_lines":0,"entry_type":"entry","immediate_finish":true,"key":"a","prepend":false,"target":"cursor","template":"* TODO %^{Task}"},{"clock_in":false,"description":"Task","empty_lines":0,"entry_type":"entry","immediate_finish":false,"key":"t","prepend":false,"target":"cursor","template":"* TODO "},{"clock_in":false,"description":"Babel","empty_lines":0,"entry_type":"plain","immediate_finish":false,"key":"b","prepend":false,"target":"cursor","template":"#+begin_src %^{Language}\n%?\n#+end_src"},{"clock_in":false,"description":"Note","empty_lines":0,"entry_type":"entry","immediate_finish":true,"key":"n","prepend":false,"target":"cursor","template":"* %^{Note}\n  %U"},{"clock_in":false,"description":"Contact","empty_lines":0,"entry_type":"entry","immediate_finish":true,"key":"c","prepend":false,"target":"cursor","template":"* %^{Name}\n  :PROPERTIES:\n  :EMAIL: %^{Email}\n  :PHONE: %^{Phone}\n  :ADDRESS: %^{Address}\n  :BIRTHDAY: %^{Birthday}\n  :END:"}]` | Org-capture templates for the **Org → Capture** submenu: named, placeholder-driven templates filed at a cursor/id/file/headline/ datetree target. Seeded with `Anything`/`Todo`/`Contact` by default; see the `vix-org-capture` crate and `crates/vix-org-capture/spec/index.md`. |
| `org_priority_highest` | `char` | `"0"` | Highest-priority character for a headline's `[#X]` priority cookie (**Org → Priority**). "Highest" sorts first — Vix's default is numeric (`'0'` highest .. `'9'` lowest), unlike Emacs's default `'A'`..`'C'`. |
| `org_priority_lowest` | `char` | `"9"` | Lowest-priority character; see `org_priority_highest`. |
| `org_priority_default` | `char` | `"0"` | Priority given to a headline that had no cookie yet, by **Org → Priority → Increase/Decrease**. |
| `org_agenda_files` | `Vec<String>` | `[]` | The Org agenda's explicit file list (workspace-relative paths), managed by **Org → Agenda → File List**. Empty (the default) means every `.org` file in the project — the pre-list behavior. |
| `time_zone` | `String` | `"UTC"` | Active time zone as an IANA canonical name (e.g. `"UTC"`, `"America/New_York"`). Chosen via Tools → Time Zone…; used app-wide (e.g. the clock panel). |
| `restore_session` | `bool` | `true` | Reopen the previous session (open files, focused tab, cursor positions) when Vix is launched in a workspace with no file given on the command line. The session is saved per workspace root in `session.toml`. |
| `sticky_search_highlight` | `bool` | `true` | Keep search-match highlights visible after the Find box closes ("sticky" highlights), until they are explicitly toggled off. When false, closing Find clears the highlights. |
| `ai_command` | `String` | `"claude -p {prompt}"` | Command template the **AI** menu runs over editor text. The placeholder `{prompt}` is replaced with the action's instruction; if the template also contains `{file}` it is replaced with the path of a temp file holding the input text, otherwise that file is redirected to the command's stdin. This lets you point the AI menu at any CLI assistant — `claude` (default), `codex`, `mistral`, `ollama run …`, etc. See [`Settings::ai_command_line`]. |
| `ai_diff_review` | `bool` | `true` | Review AI replace transforms (Annotate / Improve) as an accept/reject diff before applying, instead of overwriting the text immediately. On by default. |
| `editorconfig` | `bool` | `true` | Apply `.editorconfig` rules (indent style/size, trim/final-newline on save) for opened files, overriding the global settings per file. On by default. |
| `auto_pair` | `bool` | `true` | Auto-insert the matching closer when an opening bracket/quote is typed (and delete both with Backspace inside an empty pair). On by default. |
| `inline_blame` | `bool` | `false` | Show the git blame for the cursor's line inline (dimmed, end of line). Off by default; toggle via **Git → Toggle Inline Blame**. |
| `debug_adapters` | `Vec<vix_dap::DebugAdapter>` | `[]` | Configured debug adapters (DAP), matched to files by extension. Empty by default — add the adapters you have installed. |
| `test_command` | `String` | `"cargo test"` | Command run by **Tools → Run Tests**, whose output is parsed into a pass/fail tree (e.g. `cargo test`, `pytest -v`, `npm test`). |
| `project_snippets` | `String` | `"config/snippets/snippets.json"` | Project snippet file, relative to the project root. Loaded alongside the global and media-type snippet files. See the `vix-snippets` crate spec. |
| `coverage_path` | `String` | `""` | Default path to a coverage report (LCOV or Cobertura XML), pre-filled in the **Tools → Load Coverage File…** prompt. Empty means no default; Vix never generates a coverage report itself. See the `vix-coverage` crate spec. |
| `test_width` | `u16` | `40` | Width (columns) of the test-results panel. |
| `db_connections` | `Vec<vix_db::connect::Connection>` | `[]` | Saved database connections for the **DB** menu (the `vix-db` crate spec). Passwords are never stored here; they are prompted for per session. |
