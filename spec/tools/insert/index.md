# Tools: Insert

**Tools → Insert** is a submenu of fragment generators, each inserting text at
the cursor: UUID/ZID (`vix-uuid-tool`, `vix-zid-tool`), Lorem ipsum
(`vix-lorem`), [Date/Time](datetime.md) (`vix-clock-panel`), and
Markdown/HTML/SQL/[LaTeX](latex.md)/Org fragments (`vix-org` for the Org
fragments; LaTeX and the others are their own small generators). See
[`../index.md`](../index.md) for the full Tools-menu group table.

## Sub-specs

- [Date/Time](datetime.md)
